# 明日方舟 AI 自动化 Skill

让 AI 按玩家的实际需求安排《明日方舟》的日常，把刷图、找作业、推进关卡、领奖和基建生产接成一套自动化流程，减少反复查看进度和手动切换任务的时间。

当前正式版：**v1.1.1**。适用于 Windows 上的 AI 编程/执行工具，基于 MAA 与 Android 模拟器运行，附带本项目的执行源码和迁移说明。

## 它能自动帮玩家做什么

- **每日事务**：签到、领取可领奖励、公开招募、信用商店、基建收菜换班、完成后的任务奖励领取。
- **每周剿灭**：检查周报酬进度，安排尚未完成的剿灭任务；新图有适用作业时，可辅助首通及后续代理。
- **推进未通关主线**：自动继续尚未完成的主线，处理剧情与普通战斗节点，不局限于重复刷已经通关的关卡。教学关卡除外。
- **限时活动**：识别当前活动；有适用作业时，自动攻略普通、突袭、EX 等关卡，并按玩家要求安排后续材料刷取。
- **查找与更换作业**：结合已有干员与练度寻找可用作业，交给 MAA 执行；作业不适合时，在用户允许的范围内更换方案。
- **安排理智与材料**：按玩家设置的优先级安排剿灭、活动、主线和材料补充，不反复重打已有完成记录的内容。
- **按库存调整基建**：根据固源岩、源石碎片、赤金和龙门币储备，调整刷取、生产、贸易订单与干员安排；支持以搓玉为目标的生产策略。
- **肉鸽探索、领奖和加点**：支持持续探索、结算后自动领取积累奖励、分配常驻成长点，并接续同一主题的任务；当前重点为银凇主题。
- **周期与长期玩法**：包含保全奖励进度/封顶检查、生息演算等流程；具体玩法的执行能力以现有模块和适用作业为限。
- **异常续接与结果汇报**：处理已覆盖的中断和异常，接续未完成步骤；结束后汇总做了什么、理智用在哪里、还有哪些未完成，并按约定停止和清理。

这些能力在完成本机配置、获得用户任务授权后使用，不意味着任意关卡、阵容或活动都能保证通关。

## 从玩家实际操作需求出发

开发重点是少接管、少重复操作：不只是让软件执行一份固定任务，还要能根据今天的活动、已有进度、仓库库存和生产目标，安排接下来该做的事。

例如，玩家可以设置“每周剿灭 → 消耗理智的限时活动 → 未完成主线 → 库存与生产需求”的优先级；需要搓玉时，联动材料补充和基建生产；想刷肉鸽时，把探索、领奖和加点放在同一个任务里。这里是可配置的使用目标，不强制所有人采用同一套资源策略。

MAA 提供刷图、招募、基建及作业执行等基础能力；本项目提供上层 AI 编排、未通关内容推进、跨任务衔接、状态复核和异常续接。两者配合使用，本项目不替代或重新分发 MAA。

## v1.1.1 包含什么

- 358 份既有 Python 代码与 1 份路径适配文件，覆盖每日编排、主线、肉鸽、识别、恢复、结果汇报和共用宿主能力。
- Skill 入口、功能说明、任务契约示例、本机配置示例和源码完整性清单。
- 给接收方 AI 使用的源码入口与环境对接说明。

这是可供 AI 迁移的源码 Skill，不是一键安装器。把仓库或 ZIP 交给接收方 AI，由它复用现有代码、安装所需公开依赖，并完成本机接口配置；不需要依据功能介绍重新开发核心业务。

## 使用前提与边界

- Windows 10/11 64 位，MAA、支持的 Android 模拟器、Python 与 ADB；当前识别/坐标基线为 MuMu 12、横屏 **1920×1080**。
- AI 宿主需要具备本地文件、命令执行和图像理解能力；跨宿主接口由接收方配置，不能将可迁移理解为所有宿主已经逐一验证。
- MAA、模拟器、公开库及 OCR 模型由接收方 AI 按本机环境从可信来源安装，本包不重复分发这些软件。
- 游戏由用户自行登录。账号、密码、通关记录和作者私人运行数据不随包迁移。
- 教学关卡、验证码、缺少适用作业或未覆盖的特殊活动可能需要人工处理；困难关卡和高难肉鸽不保证通关。肉鸽通关后自动提高挑战难度等扩展仍在完善。
- 已有功能在源项目按相应范围使用和验证；本发布包完成离线源码、路径、结构、隐私及包内容检查，未在接收方的新电脑完成整套游戏实跑。
- 理智、药剂、源石、重试和运行时长遵守玩家设置；异常恢复不等于无限重试或全天候无人值守保证。
