# 日常与单项
默认日常用 `python ark.py run daily`。仅要求一项时，从[目标表](capability-map.md)选该项；只想按自己的顺序做几项，用[自选日常](entrypoints-v125.md)。没有新开放内容，不回地图复查已验收首通；材料刷取仍按本轮目标、余额和结算单独计算。

只有现有代理且周奖励未满才需补周剿灭。活动过期不再签到。保全按当前周期奖励，肉鸽按主题区分奖励和永久加点，不把其中一项完成当成另一项完成。

<a id="committee-live-visual-takeover"></a>
## 特殊活动：战时新闻委员会
仅当本期确有该玩法，才进入活动的每日新内容。逐页看已开放的报纸，已验完成的不重新排版；未解锁的不算漏做。模板无法识别时，由当前执行 AI 按版面和可放置素材接手；发行后的销量、奖励和该份报纸的完成状态分别核实。一份发行成功不代表后面几份也完成。全部完成或活动结束后停用此项。

出现意外页面见[原地接回](continuity-and-signin.md#take-over-an-unfinished-step-in-place)，日终只补新待办。
