# 悖论模拟（Beta）

用户说“帮我打一个悖论模拟”时，在完整包的 `runtime` 目录运行 `python ark.py run paradox`。若 `python ark.py list` 不含此目标，就不要改跑普通关或整套日常。已开会话沿原控制器接续，不另起模拟器。

脚本读干员列表的“悖论模拟”排序，选一张真实标有“未通过”的卡。表头记住了排序名称不等于它已生效；只有地图文件不等于本账号已解锁。点卡后若是过渡帧，先重截，不再次点卡。读到关卡标题后，匹配本机 MAA 的干员和 `mem_*` 地图，再从作业站查找并核对同一地图的作业。

详情页的“开始模拟”先打开技能选择；选好作业要求的技能后，才在该技能行出现的“开始模拟”页调用 MAA 的 `ParadoxCopilot`。同时核对任务回调和游戏的通关画面；同关“已完成模拟作战”可验收。只看到队列结束不算通过，不按理论首通奖励推算到账。

一次最多打一关，不消耗理智，不为开模拟去培养干员，不加入默认日常。没看到可确认的候选，不能说全账号都已打完；选技能页不符合已适配的三槽布局、没有匹配作业或结果不明时，保留原因交执行 AI，不盲点或自动重打。单关分段实机已验证，连续无人值守清多关未验。
