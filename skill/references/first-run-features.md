# 首次设置与可选功能

首次接入只确认本机／账号、资源边界和要启用的模块。已有设置直接沿用；不要求用户把所有功能都配置一遍。

- 默认日常沿已发布链，不因新增功能重排、另建定时或强制迁移MAA列表模式。
- 用[功能地图](capability-map.md)介绍实际入口。保全编队是我们的桥接，不是原生SSSCopilot自带的选项。
- [干员培养](operator-and-voucher-interfaces.md#干员培养可选)可选升级、专精和模组；可采用近期自在道爷参考，也可替换干员、顺序和目标。未启用不影响日常。
- [凭证兑换](operator-and-voucher-interfaces.md#凭证兑换)按用户选择商品范围、完整预算和对象，不继承别人的偏好。
- 用户可让自己的AI修改本地配置；只改相关部分，未接入项明确说明，Beta只标具体功能。

| 数据 | 是否分享 |
| --- | --- |
| 通用接口、流程、带来源的公开作业参考 | 可以；参考方案需用户选择后才使用 |
| 用户的资源策略、路径、顺序、预算 | 留在本地，可自行修改 |
| 账号进度、库存、截图、日志、凭据 | 不随包分发 |

公开参考中的干员名字和要求不代表发布者或接收方已经拥有／达标。实际结果写[当前账号记录](account-progress.md)，不另造完成清单。版本正常递增；更新由用户自己的AI按[本地合并](release-notices-and-local-merge.md)保留已有调整，不重复初始化。
