# 首次使用选什么？
先按[接入说明](receiver-integration.md)绑定自己的设备、游戏包和账号，再决定用默认日常还是[只做几项](entrypoints-v125.md)。不需要一次配置所有玩法。

- 基建沿自己的布局、排班和无人机目标；药剂、源石和商店预算分别设置。
- [干员培养](operator-and-voucher-interfaces.md)不默认启用。可选带作业来源的挂机阵容参考，也可自订干员和次序；不要把示例当作本人队列。
- [凭证兑换](operator-and-voucher-interfaces.md#凭证兑换)单独选择；普通信用商店不自动包含它。
- 新增或更新功能时保留自己的配置和[已验进度](account-progress.md)，不用每次重做首次设置。
