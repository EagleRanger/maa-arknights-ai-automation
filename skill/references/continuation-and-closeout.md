# 中断后接着做，还是已经做完？
在 `runtime` 目录查看原模块会话：`python ark.py resume --output 原输出目录 --check-only`。同一个任务不用重开游戏或新建一份计划。

| 返回 | 应该做什么 |
| --- | --- |
| `continue_remaining` | 去掉 `--check-only`，只接脚本列出的未执行项。 |
| `reconcile_effect` | 上次可能已点击、开战或扣费。看原结算或当前页面确认效果，不重新提交。 |
| `terminal_no_replay` | 已结束，不重新跑。若用户有新要求，把它当新任务。 |
| 找不到有效会话、账号不同或状态过期 | 不猜旧进度；从原回执核定剩余项。 |

正式每日先看当天日报；模块接续用自己的输出目录。永久或本周期已验证的事项与今天新增的待办分开，不为确认昨天的结果再次上号。已完成的战斗不因收尾失败而重打。

还有已选任务时保留游戏；全部完成时收取新出现的招募、基建、任务奖励，再正常退出本次程序。需要显式结束模块会话时用 `python ark.py finish --output 原输出目录`；玩家要求留在现场则保留。
