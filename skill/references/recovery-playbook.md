# 卡住时先看什么？
| 现场 | 处理 |
| --- | --- |
| 加载或黑色过渡帧 | 再取当前帧，不重复点击已经按过的开始。 |
| 误进说明页或活动弹窗 | 仅关闭能确认安全的控件；返回有效页面就地接回，不要求每次先到首页。 |
| 关卡、数字或按钮文字读错 | 局部放大重读，核对所在面板、目标和难度；地图背景的关名不代表右侧详情。 |
| 完成回调与显示不一致 | 看本次结算和原图，保留未知，不重复开战、购买或扣材料。 |
| 连续安全接回仍失败 | 保留游戏和原会话，把当前页、已尝试动作及未完成项交执行 AI；只有需要新选择才问玩家。 |

单独模块用[原会话状态](continuation-and-closeout.md)，重复报错先检查设备、账号和 MAA 队列是否仍是本次目标。
