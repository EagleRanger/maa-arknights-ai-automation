# 保全派驻：编队、战斗和奖励
在 `runtime` 运行 `python ark.py run sss`。编队是保全流程的一部分，不需要另外执行“只编队”。脚本借普通 Copilot 的编队能力选人和技能，再交回所选区域的 SSS 作业战斗。进入已有“开始部署”页时不要求重新编一遍。

**已有适配区域**：用该区域的 SSS 作业及匹配本账号的阵容。**新增区域**：先核作业的 `opers`、`tool_men`、装备与策略；在实际使用的引擎配置 `SSS_FORMATION_PROFILES[region_name]` 中指定 20 个不重复首选，每项含 `name`、`profession`、`skill`；核心标 `core: true`，备选放 `alternates`。这不是自动扫描账号组队；区域选择器也必须能找到该区域的作业。只换编队名单不会让新图自动可用。

遇到缺人或卡在选人时，先看实际区域、作业是否一致及编队回调。20/20 是人数，不证明核心与技能全对；编队未完成不算战败。编队完成后普通 Copilot 停止，由 SSS 作业接手，不去普通关开战。委托会消耗代理卡，不因编队失败自动改用。

本轮实际通关、区域奖励和本周期封顶分别看对应结果。若本周期已经完整验收，不再次进图；刷新后再查。
