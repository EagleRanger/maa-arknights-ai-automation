# 可选功能与限制
Beta 标在具体功能，不改变默认日常。先用 `python ark.py describe 目标` 查当前安装实际接通的能力。

- [干员培养与凭证](operator-and-voucher-interfaces.md)：专精与模组只处理指定账号目标；绿、黄票没有通用自动购买入口。
- [悖论模拟](paradox-simulation.md)：一次找一名已开放且未通过的干员；不保证自动清完全部。
- [教学关](tutorial-ai.md)：按实图理解提示，无法继续转人工，不假报通关。
- [卫戍角标与高难复盘](hard-trial-review.md)：可尝试，角标需要同策略前后实图；部署建议不会自动改写作业。
- [肉鸽与生息](roguelike-rewards.md)：领取已有奖励不等于展开一局；需要选择或余额不明时由执行 AI 接手。
