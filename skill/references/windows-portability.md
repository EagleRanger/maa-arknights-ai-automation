# Windows 上连不上时怎么查
先按[安装与配置](receiver-integration.md)填写本机路径。从 `runtime` 运行 `python ark.py check --task daily --probe`；只用单项时换成对应目标。不要复制示例端口或其他人的账号文件。

| 现象 | 优先排查 |
| --- | --- |
| ADB 不在线或连错实例 | 用本机 MuMu CLI 查目标实例实际地址，只选该设备和游戏包。不同安卓版本的 adb.exe 可能在安装目录 shell 下，也可能在 nx_device 下对应版本的 shell 目录。不要只凭一条例子建目录联接。 |
| 按钮整体偏移 | 检查安卓原始截图为横屏 1920×1080、16:9；客户端有异形屏适配时设为 0。桌面窗口大小不是安卓截图尺寸。 |
| MAA 窗口不响应 | 确认打开了配置绑定的 MAA，程序权限一致，更新向导已结束且队列空闲。不要再启第二份抢控制权。 |
| Python 或 OCR 启动失败 | 指向真实解释器而非 Windows 商店别名；主环境与[独立 OCR 环境](local-ocr-setup.md)分别检查。 |
| 截图正确但点击不生效 | 检查设备连接与触控返回，观察操作后的新画面。不要按桌面缩放猜游戏坐标。 |

不同账号、模拟器实例和 MAA 配置分开保存；不为退出本次游戏关闭共享 ADB 服务或其他模拟器。
