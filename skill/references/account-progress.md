# 哪些事只需要验证一次？
完成记录属于具体账号和目标。首次用游戏结算、实际等级或领取状态确认后，后续先读本地记录，不为查重再次上号。不要复制其他账号的进度，也不要把请求已提交写成已完成。

| 事项 | 记录能用到什么时候 |
| --- | --- |
| 已核实的三星、专精、模组、肉鸽永久加点 | 对应干员、技能、模组分支或主题版本不变时沿用。普通三星不是突袭通关。 |
| 复刻任务、周奖励、限时兑换 | 只在同一次活动或同一周期内有效。复刻任务不能直接继承原活动首通。新解锁只补新增项。 |
| 今日刷关、招募、制造、任务奖励 | 只证明该轮实际发生的结果，不能抵明天的理智或后续新产生的待领。 |

账号变更、玩法改版、新任务开放或结果矛盾时，只重验受影响的项；缺证仍记未知。肉鸽分主题处理见[领奖与加点](roguelike-rewards.md)。

要查一个主题为何被跳过，可在 Skill 根目录运行 `python scripts/account_progress_v1.py --help`。按其参数传入自己的数据目录、客户端、UID、主题和版本，只读查看判断，不会开游戏。
